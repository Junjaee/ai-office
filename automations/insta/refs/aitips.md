## 이 계정(aitips)의 카드 골격 — 뉴스형일 때
1. 표지: 제목 = "<무엇> 출시/업데이트" 형태의 **뉴스 헤드라인**(예: "Windows용 제미나이 앱 출시"), 부제 = 한 줄 이득("Alt+Space 한 번이면 화면 위에 AI 비서")
2. 카드 1: 언제·누가·무엇 (날짜 명시) + 공식 화면 이미지
3. 카드 2~4: 장점·달라진 점 (하나씩, 실제 화면·예시 프롬프트)
4. 카드 5: 켜는 법·쓰는 법 (단축키·메뉴 순서)
5. 카드 6: 받는 곳·조건 (주소, 지원 OS, 요금·구독 여부)
6. 마무리: 저장·공유 + 댓글 유도

명령어/따라 하기형일 때는 B·C 구조를 따른다: 훅(숫자·결과물) → 문제 → 해결 → 구체 예 3~5 → 받기·저장.
