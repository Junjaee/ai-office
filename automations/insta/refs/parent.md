# 참고 구조 — 육아 꿀팁·혜택 계정

문장을 베끼지 말고 흐름만 따른다. 한국 육아 정보 계정(맘카페·육아 인스타 매거진)에서 반응이 좋은 두 가지 꼴.

## A. 혜택 알림형 — "돈 되는 제도"

```
이번 달부터 부모급여 100만 원, 아직 신청 안 하셨어요? 👶      ← 1줄: 금액 + 소외감
0~11개월 아이가 있으면 매달 100만 원, 12~23개월은 50만 원이에요.  ← 대상·금액 (숫자)
신청은 복지로(온라인) 또는 주민센터. 출생 60일 안에 하면 출생일부터 소급돼요.   ← 방법·조건
놓치기 쉬운 것: 어린이집 다니면 보육료로 전환되고 차액만 현금.   ← 함정 하나
저장해 두고 오늘 신청하세요. 해당되는 친구에게도 공유!             ← 행동 유도
💬 댓글에 '신청' 남기면 신청 순서 정리본을 DM 으로 보내드려요.     ← 댓글 유도
```
배울 점: 첫 줄에 금액, 둘째 줄에 대상, 셋째 줄에 방법. 함정 하나가 저장을 만든다.

## B. 육아 방법형 — "오늘 밤 바로 해 보는 것"

```
밤에 30분마다 깨는 아이, 이거 하나 바꿨더니 달라졌어요 🌙        ← 결과 먼저
생후 6개월 기준, 소아과학회가 권하는 건 '같은 시간, 같은 순서'예요.  ← 근거 + 나이 기준
목욕 → 수유 → 책 한 권 → 불 끄기. 순서를 매일 똑같이.               ← 방법 4단계
3일은 더 울 수 있어요. 일주일 지나면 대부분 안정된다고 해요.        ← 기대치 관리
오늘 밤부터 해 보고 댓글로 알려 주세요.                             ← 참여 유도
```
배울 점: 나이 기준과 근거 기관을 꼭 쓴다. 겁주는 말 대신 "대부분 ~된다고 해요" 로.

## 금지
- 병·사고·학대 사건 기사, 특정 브랜드 분유·기저귀 홍보, 확인 안 된 민간요법.
