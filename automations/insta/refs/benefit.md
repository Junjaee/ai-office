# 참고 구조 — 돈 되는 혜택 알림 계정

문장을 베끼지 말고 흐름만 따른다. "신청만 하면 받는 돈" 계정들이 쓰는 꼴.

## A. 지원금·환급 알림형

```
신청만 하면 30만 원, 이번 주 금요일까지예요 💸                     ← 금액 + 마감
대상은 만 19~34세 청년 중 월 소득 ○○ 이하. 조건 하나만 맞으면 돼요.  ← 대상 (숫자)
신청은 정부24 → '○○ 지원' 검색 → 본인인증. 5분이면 끝나요.           ← 방법 (어디서, 몇 분)
받은 뒤 6개월 안에 써야 하고, 안 쓰면 소멸돼요.                      ← 조건·함정
저장해 두고 오늘 신청하세요. 해당되는 친구에게 공유!                  ← 행동 유도
💬 댓글에 '신청' 남기면 조건 체크리스트를 DM 으로 보내드려요.          ← 댓글 유도
```

## B. 제도 변화형 — "다음 달부터 달라지는 것"

```
10월부터 통신비 최대 2만 원 줄어드는 사람 👀                        ← 결과 먼저
바뀌는 건 하나: ○○ 요금제 가입자는 자동 적용, 아니면 앱에서 전환.     ← 무엇이 바뀌나
내가 해당되는지 확인: 통신사 앱 → 요금제 → '○○' 표시.                ← 확인 방법
근거: 과기정통부 ○월 ○일 발표.                                       ← 근거 기관·날짜
```

## 금지
- 정치 공방, 예산 논쟁, 확인 안 된 금액, 특정 업체 광고. 대상·금액·기간 셋 중 하나라도 확인이 안 되면 그 글은 쓰지 않는다.
