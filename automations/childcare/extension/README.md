# 시간제보육 예약기 (크롬 확장)

아이사랑 예약 화면에서 **예약하기 · 확인 · 확인을 될 때까지 빠르게 되풀이**한다. 그게 전부다.

## 나누는 일

| | 누가 |
|---|---|
| 로그인 → 기관 → 아동 선택 → 이용정보 신청 → 반·시간 고르고 **추가** | 사람 |
| 그 상태에서 **예약하기 광클** | 이 확장 |

그래서 단추가 셋뿐이다 — **시작 · 멈춤 · 복사**.

## 왜 exe 가 아니라 확장인가

아이사랑은 **개발자 도구를 막는다** — 페이지가 `disable-devtool.0.3.7.min.js` 를 올린다(2026-11-11 확인).
Playwright·CDP·내장 브라우저는 전부 그걸 쓴다. 붙기만 하면 메인으로 튕기거나 연결이 끊겼다.
초반에 겪은 "메인으로 튕김", GitHub 서버에서 로그인 화면이 안 뜨던 것, 전용 크롬이 죽던 것이 **전부 같은 원인**이었다.

확장의 content script 는 개발자 도구를 쓰지 않는다. 사이트가 막아 둔 것을 푸는 게 아니라 건드리지 않는 길이다.

## 설치 (한 번만, 30초)

1. 크롬 주소창에 `chrome://extensions`
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 고르기

고친 뒤에는 그 화면에서 **↻**, 그리고 아이사랑 페이지 **F5**.

## 쓰는 법

예약 화면에서 **칸을 고르고 [추가] 까지** 누른 뒤, 오른쪽 아래 패널의 **[시작]**.

```
목록에 1건 있어요 — [시작]을 누르세요
목록 1건 — ☑ 들꽃향기 2026-11-26(목) 09 : 00 ~ 16 : 00
1번째 — 아직 예약 가능한 시간이 아닙니다.
대기열 — 앞에 842명 · 예상 0시간 1분 20초
성공 — 1건 예약 중 1건 예약되었습니다. (21번째)
```

머리글을 누르면 접힌다. **[복사]** 로 기록을 통째로 가져갈 수 있다.

## 한 바퀴 (실제 화면에서 확인, 2026-11-12)

```
예약하기(fnSave)
  → "예약하시겠습니까?"                  layer-confirm-popup-contents2
  → 확인                                 layer-confirm-popup-confirm2
  → 넷퍼넬 대기열                         NetFunnel_Skin_Top      (몰릴 때만)
  → "아직 예약 가능한 시간이 아닙니다."    layer-alert-popup-contents2
  → 확인                                 layer-popup-close2      ← 닫아야 다시 누를 수 있다
```

**한 바퀴 113ms = 초당 8.9회** (2026-11-12 아이사랑 실제 화면에서 3초에 27번).

단계별로 재 보면 깎을 데가 없다.

| 단계 | 실측 |
|---|---|
| 확인창 뜨기 | **0ms** (화면 안) |
| 확인 누른 뒤 결과까지 | **107ms** ← 서버 왕복, 이게 전부 |
| 결과창 닫기 | **0ms** |
| 다음 발사까지 쉼 | **0ms** (`GAP_MS = 0`) |

첫 발만 313ms 였다(연결 데우기). 더 줄이려면 응답을 안 기다리고 겹쳐 쏴야 하는데,
확인창이 하나뿐이라 서로 꼬인다.

멈추는 경우는 셋뿐이다.

| | |
|---|---|
| **성공** | `예약되었습니다` 등 |
| **다시 해도 안 될 사유** | `이미 예약된 시간입니다` 처럼 "아직" 이 아닌 거절 |
| 30분 지남 / [멈춤] | |

## 함정 (실제 화면에서만 드러났다)

1. **거절 문구는 `layer-alert-popup-contents2` 에 뜬다.** `layer-popup-contents` 계열만 보면
   응답을 못 읽고 한 번 쏜 뒤 멈춘다.
2. **같은 id 가 문서에 두 벌씩 있다** — 숨은 것과 보이는 것. `getElementById` 는 첫 번째(숨은 것)를
   집으므로 글도 못 읽고 확인도 못 누른다. 확인을 못 누르면 창이 안 닫혀 다음 발사가 막힌다.
   → 같은 id 를 전부 훑어 **보이는 것**을 쓴다.
3. **물어보는 창을 결과로 세면 안 된다.** `layer-confirm-popup-*` 는 누르기만, `layer-alert-popup-*`·
   `layer-popup-*` 만 답으로 본다. 안 가르면 "예약하시겠습니까?" 를 결과로 읽어 성공을 실패로 판정한다.
4. **대기열에서는 아무것도 누르지 않는다.** `NetFunnel_Skin_Top` 이 보이면 응답을 끝까지 기다린다.
   사이트가 대기 화면에 직접 적어 둔 경고 — "새로고침, 뒤로가기 또는 재접속하시면 대기시간이 더 길어집니다."

## 알아 둔 사실

- **자리 숫자가 보여도 예약이 되는 건 아니다.** 자정이 지나면 그날의 14일 뒤 줄이 미리 생기고
  09~17시 전부 `3` 으로 보이지만, 9시 전에는 신청이 거절된다.
- **세션은 1시간**이고 지켜보는 동안 계속 갱신된다. 그래도 **8시 50분쯤 로그인하고 준비하는 것이 안전**하다.
  밤새 켜 두지 말 것.
- 새로고침해도 **반 설정은 풀리지 않는다.**

## 손잡이

`engine.js` 맨 위 두 개뿐이다.

```js
const GAP_MS = 120;                  // 한 바퀴 돌고 다음 발사까지
const GIVE_UP_MS = 30 * 60 * 1000;   // 이만큼 해도 안 되면 그만둔다
```
