# 의사일정 → 캘린더

회의 폴더에 들어온 의사일정 파일을 읽어 530호 캘린더에 회의 일정을 넣는다. AI 호출 없음.

```
상임위 메일 → 수신함 정리(20261126_전체위 폴더로 옮김) → **의사일정**(캘린더에 넣음) → 발언 요약 · 주말 일정
```

## 하는 일

1. **읽기**(`read`) — 위원회 폴더 아래 오늘 이후 날짜의 회의 폴더(`YYYYMMDD_…`)에서 이름에 "의사일정"이 든 파일을 찾아 첫 줄을 읽는다.
   첫 줄은 늘 `제11차 재정경제기획위원회 2026. 11. 26.(목) 10:00` 모양이다.
2. **넣기**(`sync`) — `[재경위] 제11차 전체회의` 로 캘린더에 넣는다. 끝 시각은 `end_time`(18:00).

## 규칙

- 같은 회의는 한 번만 넣는다(회의마다 id 가 정해져 있다). 여러 번 돌려도 같다.
- **사람이 지운 일정은 다시 넣지 않는다.**
- 사람이 이미 넣은 일정(같은 시작 시각 + 제목에 "재경위"·"예결위", 재경위는 "인사청문회"도 — 설정 `same_as`)이 있으면 넣지 않는다.
- 의사일정이 고쳐져 시각이 바뀌면 캘린더의 시각도 고친다(캘린더에서 손으로 바꾼 시작 시각은 의사일정대로 돌아간다).
- 첫 줄을 못 읽으면 넣지 않고 카드에 "못 읽은 의사일정 N개"로 알린다.
- **소위원회는 넣지 않는다** — 제목의 "재경위"가 발언 요약을 전체회의 채널로 깨우기 때문이다.
- 위원회 폴더 위치는 `automations/sort/config.actions.yaml` 의 `committees` 를 그대로 읽는다.

## 언제 도나

상임위 메일 실행(`mail.yml`)이 수신함 정리 다음에 이어서 돌린다. 사이트의 시작 단추(`agenda.yml`)로도 돌릴 수 있다.

## 이 PC 에서

```bash
python automations/agenda/run_agenda.py --dry-run   # 넣지 않고 무엇을 넣을지만
python -m pytest -q automations/agenda
```

비밀값: `GOOGLE_*`(드라이브 읽기 + 캘린더 일정 쓰기 `calendar.events`).
