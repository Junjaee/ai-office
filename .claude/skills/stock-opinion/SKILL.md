# 종목 해석 쓰기

대시보드의 종목 한 장(`/home/stock/<시장>/<기호>` — 미국 `us`, 국내 `kr`)에 실리는 **AI 해석**을 대화에서 써서 저장하는 절차다. 매일 도는 자동화는 AI 를 부르지 않는다 — 해석은 사용자가 요청할 때만 쓴다. 해석은 투자 권유가 아니라 "무엇을 보고 어떻게 읽었는지"를 남기는 기록이다.

## 절차

1. **종목 자료 읽기.**
   `curl -s "https://ai-office.smartjohn-d34.workers.dev/api/stock?market=<us|kr>&ticker=<기호>"`
   - 시장은 `market=us`(미국, 기호는 `NVDA` 꼴) 또는 `market=kr`(국내, 기호 자리에 **6자리 종목 코드** `005930`). 국내는 `doc.rec.name_local` 이 한글 이름, 금액은 원(`doc.rec.currency` = `KRW`), 공시(`doc.events`)는 없다.
   - 쓸 것: `doc.rec`(계산값) · `doc.checks`(점검표) · `doc.lenses`(발굴 관점) · `doc.events`(공시) · `doc.news`(기사 제목) · `opinions`(지난 해석).
   - `doc` 가 null 이면 자료가 아직 없는 것이다. 관심 종목에 담고 다음 갱신(미국 화~토 07:00 · 국내 월~금 16:30) 뒤에 하자고 안내한다.
2. **필요하면 더 읽는다.** 기사 본문·실적 발표 자료를 웹 검색으로 찾아 읽는다. 읽은 것은 출처(재무·시세·뉴스·전망 중 어디인지)를 기억해 둔다.
3. **쓴다.**
   - 한 줄 결론: 300자 안.
   - 좋게 보는 근거 3~4개, 나쁘게 보는 근거 3~4개. 근거마다 출처를 `재무` · `시세` · `뉴스` · `전망` 중 하나로 단다(근거 한 개는 300자 안).
   - 다음 실적에서 볼 것 1~4개(항목당 200자 안).
4. **지킬 것.**
   - 문장 속 숫자는 **저장된 계산값에서만** 가져온다. 계산값에 없는 숫자(기사·실적 발표에서 읽은 것)를 쓰려면 문장 안에 출처를 적는다(예 "회사 발표에 따르면 …").
   - 등급·목표가·"사라/팔아라"를 쓰지 않는다. 저장 스크립트가 금지어(목표가, 매수/매도 추천, 사라/팔아라, 비중 확대/축소 등)를 거르고, 걸리면 저장하지 않고 종료 코드 2 로 끝난다. 고쳐서 다시 저장한다.
   - 근거와 **갈림길**을 쓴다 — 무엇이 확인되면 좋아지고, 무엇이 확인되면 나빠지는지.
   - 번역투를 쓰지 않는다. 우리말답게, 내용과 수치는 그대로.
5. **저장.** 위 내용을 JSON 파일로 만들어 개인 폴더 `ai-home/` 아래에 둔다(커밋되지 않는다). 그리고
   `python automations/analyst/save_opinion.py <시장> <기호> --file <경로>`  (시장은 `us` 또는 `kr`)
   주가·기준일·다음 실적일은 스크립트가 사이트 자료에서 채운다. 환경변수 `LIVE_TOKEN` 이 있으면 머리글로 보낸다.
6. **확인.** 사이트 `/home/stock/<시장>/<기호>` 에서 반영됐는지 본다. 사용자에게 한 줄 결론과 주소를 알리고, **투자 권유가 아니며 판단은 직접 하셔야 한다**는 점을 한 줄 덧붙인다.

## JSON 예시 (가상의 회사 `EXAMPLE` — 숫자도 지어낸 것)

```json
{
  "verdict": "매출은 빠르게 늘지만 빚 부담이 커서, 다음 실적에서 현금 사정이 나아지는지가 갈림길이에요.",
  "good": [
    { "text": "최근 분기 매출이 전년보다 12.3% 늘었어요.", "src": "재무" },
    { "text": "주가가 20일 평균 위에서 움직이고 있어요.", "src": "시세" },
    { "text": "새 고객사 계약을 발표했다는 기사가 나왔어요(기사 제목 기준).", "src": "뉴스" }
  ],
  "bad": [
    { "text": "순부채가 연간 영업이익의 3.1배라 이자 부담이 커요.", "src": "재무" },
    { "text": "1년 최고가보다 18.0% 아래에 있어요.", "src": "시세" },
    { "text": "시장 전망치는 올해 이익 증가가 둔해질 것으로 보고 있어요.", "src": "전망" }
  ],
  "watch": [
    "다음 실적 발표에서 쓰고 남은 현금이 흑자로 돌아서는지",
    "빚을 갚는 계획이 구체적으로 나오는지"
  ]
}
```

저장 후 `python automations/analyst/save_opinion.py us EXAMPLE --file ai-home/example.json` 꼴로 부른다(실제로는 요청받은 종목 기호를 쓴다).
