# 카드문자 전달 (안드로이드 앱)

등록한 **발신번호(카드사)** 에서 온 문자를 지메일에 `[카드SMS]` 메일로 넣는다. MacroDroid 대체(2026-09-22). 뒤는 기존과 같다:
가계부 자동화(`automations/ledger`)가 그 메일을 읽어 시트에 날짜순으로 넣고, Worker 가 1분마다 새 메일을 보면 바로 깨운다(`worker/gmail.ts`).

발신번호·전송 조건은 **앱 화면에서**, 구글 계정은 **PC 에서 만든 설정 파일을 불러와서**(폰에서 구글 로그인은 하지 않는다 — 사용자 결정 2026-09-23).

## 설치 (폰, 1회)
1. `ai-home/01_가계부/카드문자전달.apk` 를 폰으로 받아 설치. 드라이브 앱·지메일은 APK 를 막으니 **크롬으로 드라이브 직접 링크**를 열거나(파일 → 공유 링크에 `&export=download`), Claude 앱 첨부, USB 케이블, 텔레그램 "나에게 보내기" 중 하나.
2. **Play 프로텍트가 설치를 막으면**(문자 권한 앱을 스토어 밖에서 깔 때 기본 차단): 차단 화면의 "자세히 → 무시하고 설치", 안 되면 Play 스토어 → 프로필 → Play 프로텍트 → ⚙ → "Play 프로텍트로 앱 검사" 끄고 설치 후 다시 켠다(깔린 앱은 안 지워짐, 경고 뜨면 "앱 유지"). 그래도 막히면 USB 디버깅 켜고 PC 에서 `adb install`.
3. 앱 열기 → **[설정 파일 불러오기]** → 파일 선택창 왼쪽 메뉴(≡) → Drive → `내 드라이브 › dev › 자동화 › ai-home › 01_가계부 › 카드문자전달-설정.json` 선택(화면에 `✓ 구글 계정: 설정 파일 불러옴`). 파일은 PC 에서 `python android/cardsms/tools/make_token.py`(브라우저 허용 1회)로 만든다 — 이미 있으면 그대로 쓴다.
4. **발신번호 추가**: 카드사 번호 입력(예 `1577-6200`, 메모 `현대카드`) → [추가]. 여러 개면 반복. 번호는 하이픈·공백·`+82` 상관없이 같은 번호로 본다. **번호가 하나도 없으면 아무것도 보내지 않는다.**
5. **[문자 권한 허용]** → **[배터리 최적화 제외]**(허용) — 이걸 안 하면 며칠 뒤 멈춘다(MacroDroid 가 멈췄던 이유와 같음).
6. **[테스트 전송]** → 잠시 뒤 [기록 새로고침]에 `✓ 전송` 이 보이면 끝. 지메일에 `[카드문자앱 테스트]` 메일이 온다(가계부는 무시함).
7. 삼성: 설정 → 배터리 → 백그라운드 사용 제한 → "절전 예외 앱"에 이 앱이 있는지, "딥 슬립 앱"에 없는지 확인.

## 동작
- 등록 번호에서 온 문자만 보낸다. 기본은 **전부 전송**(내용 무관). 체크를 끄면 키워드(기본 `승인, 취소`)가 있을 때만.
- 승인이 아닌 카드사 문자(거절·안내)가 섞여도 가계부가 알아서 건너뛰고 라벨을 붙인다.
- 인터넷이 없으면 저장해 두고 연결되면 보낸다(재부팅 후에도). 실패는 30초→1분→2분… 최대 20회.
- 앱이 가진 구글 권한은 **메일 넣기(gmail.insert)** 뿐(설정 파일의 토큰). 메일 읽기·보내기는 못 한다.
- 최근 기록에는 시각·발신번호·본문 앞 20자·결과만 남는다. 새 카드 번호가 필요하면 기록의 발신번호를 보고 추가한다.
- 폰에서 구글 로그인(임시 서버·커스텀 스킴)은 두 번 시도해 실패·복잡해서 버렸다(2026-09-23). 설정 파일 방식이 단순하고 검증됐다.

## 다시 만들기 (PC)
- 코드 고친 뒤: `gh workflow run cardsms-app.yml` → 끝나면 `gh run download <id> -n cardsms-apk` → `ai-home/01_가계부/카드문자전달.apk` 로 복사. 같은 서명키라 폰에서 덮어 설치된다(설정·연결 유지).
- 로컬 확인: `bash scripts/gradle.sh test` · `bash scripts/gradle.sh assembleDebug` (JDK 17 + SDK 34 필요).
- 서명키·비밀번호: `ai-home/01_가계부/cardsms-release.jks`, `cardsms-signing.txt` (GitHub Secrets `CARDSMS_*` 와 같은 값). 잃으면 새 키로 만들고 폰에서 삭제 후 재설치.

## 문제 해결
- 기록에 `토큰 오류` → PC 에서 토큰 다시 발급 후 폰에서 설정 파일 다시 불러오기.
- 기록에 아무것도 안 쌓임 → 발신번호가 맞는지(기록에 안 뜨면 번호 불일치), 문자 권한·배터리 최적화, 삼성 딥 슬립 확인.
- 메일은 오는데 시트에 안 들어감 → 가계부 자동화 쪽(대시보드 /home 카드) 오류를 본다.
