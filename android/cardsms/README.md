# 카드문자 전달 (안드로이드 앱)

카드 승인·취소 문자를 지메일에 `[카드SMS]` 메일로 넣는다. MacroDroid 대체(2026-09-22). 뒤는 기존과 같다:
가계부 자동화(`automations/ledger`)가 그 메일을 읽어 시트에 날짜순으로 넣고, Worker 가 1분마다 새 메일을 보면 바로 깨운다(`worker/gmail.ts`).

## 설치 (폰, 1회)
1. 폰 구글 드라이브 앱 → `dev/자동화/ai-home/01_가계부/카드문자전달.apk` 터치 → "출처를 알 수 없는 앱 허용" → 설치.
2. 앱 열기 → **설정 파일 불러오기** → 같은 폴더의 `카드문자전달-설정.json` 선택.
3. **문자 권한 허용** → **배터리 최적화 제외**(허용) — 이걸 안 하면 며칠 뒤 멈춘다(MacroDroid 가 멈췄던 이유와 같음).
4. **테스트 전송** → 잠시 뒤 "기록 새로고침"에 `✓ 전송` 이 보이면 끝. 지메일에 `[카드문자앱 테스트]` 메일이 온다(가계부는 무시함).
5. 삼성: 설정 → 배터리 → 백그라운드 사용 제한 → "절전 예외 앱"에 이 앱이 있는지, "딥 슬립 앱"에 없는지 확인.

## 동작
- 문자 본문에 `승인` 또는 `취소` 가 있으면 보낸다(앱에서 단어 변경 가능). 나머지는 폰 밖으로 나가지 않는다.
- 인터넷이 없으면 저장해 두고 연결되면 보낸다(재부팅 후에도). 실패는 30초→1분→2분… 최대 20회.
- 앱이 가진 구글 권한은 **메일 넣기(gmail.insert)** 뿐. 읽기·보내기는 못 한다.

## 다시 만들기 (PC)
- 코드 고친 뒤: `gh workflow run cardsms-app.yml` → 끝나면 `gh run download <id> -n cardsms-apk` → `ai-home/01_가계부/카드문자전달.apk` 로 복사. 같은 서명키라 폰에서 덮어 설치된다.
- 로컬 확인: `bash scripts/gradle.sh test` · `bash scripts/gradle.sh assembleDebug` (JDK 17 + SDK 34 필요).
- 토큰 다시 발급: `python android/cardsms/tools/make_token.py`(브라우저 허용) → 폰에서 설정 파일 다시 불러오기.
- 서명키·비밀번호: `ai-home/01_가계부/cardsms-release.jks`, `cardsms-signing.txt` (GitHub Secrets `CARDSMS_*` 와 같은 값). 잃으면 새 키로 만들고 폰에서 삭제 후 재설치.

## 문제 해결
- 기록에 `토큰 오류` → 설정 파일을 다시 발급해 불러온다.
- 기록에 아무것도 안 쌓임 → 문자 권한·배터리 최적화 확인, 삼성 딥 슬립 확인.
- 메일은 오는데 시트에 안 들어감 → 가계부 자동화 쪽(대시보드 /home 카드) 오류를 본다.
