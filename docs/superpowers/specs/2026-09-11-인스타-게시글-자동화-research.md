# 인스타그램 게시글 자동화 — 무엇이 필요한가 (조사·설계 초안)

날짜: 2026-09-11 · 상태: 조사 완료, 결정 대기 · **비용 원칙: 전부 무료(사용자 결정 2026-09-11)**
주력 주제: **3. AI 툴·프롬프트 꿀팁** (대기: 1 심리·뇌과학 연구, 2 건강 팩트 N가지, 4 생활 꿀팁, 5 정부 지원금)
주제 탐색 근거: `ai-side/주제탐색_2026-09-11.md`

## 0. 한 줄 요약

"자동으로 올라간다"와 "잘 나온다"는 다른 문제다. 잘 나오게 하려면 **소재 → 글 → 카드 → 업로드** 4단계 각각에 품질 장치가 있어야 하고, 주제별 차이는 코드가 아니라 **주제 프로필(설정 파일 하나)** 로 흡수해야 한다. 아래는 각 단계에 무엇이 필요한지, 무엇을 골라야 하는지의 정리다.

## 1. 전체 흐름

```
[소재 수집]  RSS·사이트에서 오늘 후보 30~50건 → 점수 매겨 3건 선정 (중복·구식·광고 제외)
     ↓
[글 생성]    Claude API: 주제 프로필 + 참고 게시물 예시 + 선정 소재 → 카드 8장 원고 + 캡션 + 해시태그 (JSON)
     ↓
[품질 검사]  자동 심사(다른 프롬프트로 채점) → 기준 미달이면 다시 생성(최대 2회) → 사실 확인(출처 URL 필수)
     ↓
[카드 제작]  HTML 템플릿 + 원고 → Playwright 로 1080×1350 JPEG 8장 (Pretendard 글꼴)
     ↓
[검토]       (처음 몇 주) 드라이브 "초안" 폴더에 미리보기 + 캡션 저장 → 사람이 보고 승인
     ↓
[업로드]     이미지를 공개 URL 에 올림 → Instagram API 로 캐러셀 게시 → 결과 기록
     ↓
[학습]       올린 글의 좋아요·저장·공유를 하루 뒤 수집 → 어떤 훅·소재가 먹혔는지 표로 남김 → 다음 생성 프롬프트에 반영
```

각 단계는 `run_insta.py` 의 하위 작업(직원) 하나씩: `topic`(소재), `write`(글), `card`(카드), `upload`(업로드). 화면에는 이 넷이 직원으로 보인다.

## 2. 단계별로 필요한 것

### 2.1 소재 수집 (topic)

**출처 후보 (AI 툴·프롬프트 주제)**

| 출처 | 형식 | 비고 |
|---|---|---|
| OpenAI 뉴스 `openai.com/news/rss.xml` | RSS | 공식 |
| Anthropic 뉴스 (비공식 미러 `rsshub.bestblogs.dev/anthropic/news`) | RSS | 공식 RSS 없음 |
| Google AI 블로그, Hugging Face 블로그 | RSS | 공식 |
| GeekNews `news.hada.io` | RSS | 한국어, 개발자 관점의 AI 툴 소식 |
| AI타임스 `aitimes.com` | RSS | 한국어 AI 전문지 |
| 지피터스 뉴스레터 `gpters.org` | 웹 | 실무 활용 팁, 스크래핑 필요 |
| Product Hunt (AI 태그) | RSS | 신규 툴 |
| Reddit r/ChatGPT, r/ClaudeAI 상위 글 | RSS(.rss) | 프롬프트 꿀팁의 원천. User-Agent 필요 |
| GitHub 트렌딩(awesome-prompts 류) | 웹 | 명령어·프롬프트 모음 |

**선정 규칙(코드)**: 24~72시간 이내 / 제목·본문에 "사용법·프롬프트·무료·업데이트·기능" 신호 / 같은 툴 소식은 하루 1건 / 이미 올린 소재(manifest)와 제목 유사도 0.8 이상이면 제외 / 광고·모금 글 제외. 후보 30건을 Claude 에 넘겨 "인스타 독자에게 오늘 가장 쓸모 있는 3건 + 이유"를 고르게 한다(점수 JSON).

**주제별 차이**: 출처 목록과 신호 단어만 바뀐다. 심리 연구면 PubMed/PsyPost RSS, 건강이면 질병관리청·Mayo Clinic, 지원금이면 정부24·복지로·보조금24 공고 RSS, 생활 꿀팁이면 커뮤니티 상위 글.

### 2.2 글 생성 (write)

**모델·비용 — 무료로만 간다.** 유료 API 키 대신 아래 두 갈래를 쓰고, 코드는 "글 생성기" 인터페이스 하나 뒤에 제공자를 바꿔 끼울 수 있게 만든다(`LLM_PROVIDER` 설정값).

| 제공자 | 비용 | 한도 | 한국어 품질 | 비고 |
|---|---|---|---|---|
| **Claude 구독(Claude Code CLI, 1순위)** | 구독에 포함, 추가 결제 없음 | 구독 플랜의 사용량 한도 안(하루 3~6회 호출이면 여유) | 최상 | 이 PC 에서 `claude setup-token` 으로 만든 토큰을 GitHub Secret `CLAUDE_CODE_OAUTH_TOKEN` 에 넣고, 워크플로에서 `npm i -g @anthropic-ai/claude-code` 뒤 `claude -p "<프롬프트>" --output-format json` 로 호출. Anthropic 공식 문서가 Pro/Max 구독자용으로 안내하는 경로 |
| **Gemini API 무료 등급(2순위, 자동 대체)** | 무료(결제 등록 불필요) | 2.5 Flash 기준 분당 10회·하루 250~500회 | 상 | Google AI Studio 에서 키 발급 → Secret `GEMINI_API_KEY`. Claude 호출이 실패(한도·장애)하면 자동으로 여기로 |
| GitHub Models(3순위) | 무료 | 상위 모델 하루 50회, 미니 150회, 입력 8천·출력 4천 토큰 | 중상 | 워크플로의 `GITHUB_TOKEN` 만으로 호출 가능(`models: read` 권한). 별도 키 없음 |
| Groq / OpenRouter 무료 | 무료 | 넉넉 | 중 | 한국어가 약해 심사(채점) 보조용 정도 |

게시글 하나에 호출은 3~4회(소재 선정 1, 원고 1~2, 심사 1)라 어느 무료 한도에도 한참 못 미친다. 프롬프트 캐싱 같은 유료 API 기능은 쓰지 않는다. **결과물 품질이 핵심이므로 1순위는 Claude 구독**이고, Gemini 는 대체·비교용이다.

**입력 구성 (system, 캐시 대상)**
1. 주제 프로필(아래 3절): 독자, 말투, 금지어, 카드 구조, 훅 패턴
2. 잘 된 참고 게시물 5~8개의 원고(우리 실측에서 1만 이상 찍은 글의 구조를 텍스트로 옮긴 것) — "이런 결로"
3. 우리가 올린 글 중 성과 상위 3개(학습 단계에서 자동 갱신)
4. 출력 스키마

**출력(구조화 출력, JSON 강제)**
```
{ "hook": "첫 장 한 줄(15자 안팎)", "sub": "첫 장 보조 문장",
  "slides": [ {"title": "...", "body": "15~20단어", "note": "출처/근거"} ×6~8 ],
  "cta": "마지막 장(저장·공유 유도)",
  "caption": "본문 300~450자, 3문단, 첫 줄이 훅",
  "hashtags": ["5개, 한국어 위주"],
  "alt_text": "...", "sources": ["url"], "claims": [{"text": "...", "source": "url"}] }
```
JSON 은 프롬프트로 강제하고(`--output-format json` 은 CLI 응답 포장, 본문 JSON 은 우리가 검증) `jsonschema` 로 검사해 어긋나면 한 번 더 요청한다. Gemini 는 `response_mime_type=application/json` + 스키마를 지원한다.

**품질 규칙 (프롬프트에 박는 것)**
- 카드 한 장 15~20단어, 첫 3장은 각각 독립된 미끼(1점·2점·3점째 장이 각각 스크롤을 멈추게)
- 리스트형("N가지", "명령어 10개")이 한국 인스타 상위 포맷의 27%로 1위(TBWA) → 기본 골격은 리스트
- 숫자·툴 이름·명령어는 원문 그대로, 지어내지 않기. 각 주장에 출처 URL 을 `claims` 에 붙이게 하고, 출처 없는 주장은 코드가 탈락시킨다
- AI 티 나는 표현 금지 목록("혁신적인", "게임체인저", "~해보세요!" 남발), 이모지 카드당 1개 이하
- 마지막 장 CTA 는 "저장해 두고 하나씩 써보세요 / 필요한 친구에게 보내기" 식으로 저장·DM 공유 유도(알고리즘 신호)

**자동 심사**: 같은 모델에 채점 프롬프트(다른 system)로 5항목 1~5점(훅의 구체성, 실용성, 사실 근거, 한국어 자연스러움, 카드 길이 규칙 준수). 합계 20 미만이면 피드백을 붙여 재생성, 2회 실패면 그날은 "초안 보류"로 끝낸다(억지로 올리지 않는다).

### 2.3 카드 제작 (card)

**방법 비교**

| 방식 | 장점 | 단점 |
|---|---|---|
| **HTML/CSS 템플릿 → Playwright 스크린샷 (추천)** | 디자인 자유도 최고, 글꼴·줄바꿈·강조가 웹 그대로, 템플릿 바꾸기 쉬움 | GitHub 서버에 Chromium 설치 필요(`playwright install --with-deps chromium`, 약 1분) |
| Pillow(파이썬 그리기) | 의존성 가벼움 | 줄바꿈·강조·레이아웃을 손으로 계산, 결과가 투박 |
| Canva/외부 API | 예쁨 | 유료, 자동화 제약 |

**규격**: 1080×1350(4:5, 피드에서 가장 크게 보임) JPEG(인스타 API 는 JPEG 만 받음), 8~10장(최대 10). 캐러셀은 첫 장 비율로 전부 잘리므로 전 장 동일 규격.

**글꼴**: Pretendard(SIL OFL, 상업 사용 가능, 저장소에 woff2 동봉) + 이모지는 Noto Color Emoji. GitHub 서버 기본 이미지에는 한글 글꼴이 없어 저장소 글꼴을 `@font-face` 로 직접 읽는다(빠뜨리면 네모 상자).

**템플릿 구조**: `automations/insta/templates/<profile>.html` 하나에 슬롯(`{{hook}}`, `{{slides}}`)을 두고, 색·글꼴·로고·페이지 표시("1/8")는 프로필 CSS 변수로. 표지 / 본문 / 마지막 CTA 세 레이아웃. 텍스트가 넘치면 글자 크기를 단계적으로 줄이는 자동 맞춤(코드로 측정).

**주제별 차이**: 색·아이콘·레이아웃 변수만 다른 템플릿. AI 툴 = 다크 배경+코드 블록 느낌, 건강 = 밝은 배경+체크 아이콘, 지원금 = 공고문 느낌(금액·기한 강조).

### 2.4 업로드 (upload)

**인스타그램 쪽 준비 (사용자가 한 번)**
1. 인스타그램 계정을 **프로페셔널(크리에이터 또는 비즈니스)** 로 전환. 크리에이터면 페이스북 페이지 연결 없이 "Instagram API with Instagram Login" 경로를 쓸 수 있다(2024-07 이후 지원).
2. Meta 개발자 계정 → 앱(Business 유형) 생성 → "Instagram" 제품 추가 → "API setup with Instagram login".
3. 앱 대시보드에서 내 계정을 **Instagram Tester** 로 추가하고 "Generate token" 으로 **장기 토큰(60일)** 발급. 내 계정만 쓰면 **앱 심사 불필요**(개발 모드로 충분).
4. 권한: `instagram_business_basic`, `instagram_business_content_publish`.
5. 토큰을 GitHub Secret `INSTA_MAIN_TOKEN` 과 계정 id `INSTA_MAIN_USER_ID` 로 저장(값은 채팅에 안 올림).

**API 흐름**: 이미지마다 `POST /{ig_user_id}/media` (image_url, is_carousel_item=true) → 부모 컨테이너 `media_type=CAROUSEL, children=[...]`, caption, alt_text → `POST /{ig_user_id}/media_publish`. 하루 100건 제한(우리는 1~3건).

**이미지 공개 URL 이 필요하다.** Meta 서버가 게시 시점에 URL 을 직접 내려받으므로 드라이브 공유 링크는 안 된다. 선택지:
- **Cloudflare R2 공개 버킷 (추천)**: 무료 10GB·전송 무료, S3 호환 API(`boto3`)로 워크플로에서 업로드, `*.r2.dev` 주소를 image_url 로. 새 비밀값 2개(R2 키). Cloudflare 계정은 이미 있음.
- 대안: 카드 JPEG 를 저장소 `public/cards/` 에 커밋해 대시보드 사이트에서 서빙 — 새 설정이 없지만 배포(2~3분)를 기다려야 하고 저장소가 커진다. 임시용.

**토큰 갱신**: 장기 토큰은 60일 만료, 발급 24시간 뒤부터 `GET graph.instagram.com/refresh_access_token?grant_type=ig_refresh_token` 으로 갱신 가능. 갱신 워크플로를 30일마다 돌리되, 갱신된 값을 GitHub Secret 에 다시 쓰려면 `gh secret set` 권한(PAT)이 필요 → 처음엔 **50일마다 대시보드에 🟡 "토큰 갱신 필요" 배너**를 띄우고 사용자가 새 토큰을 넣는 방식이 가장 단순하다(토큰 만료일을 상태 파일에 기록).

**주제별 차이**: 없음. 계정별 토큰만 다르다(`INSTA_<계정>_TOKEN`).

### 2.5 검토(사람) 단계

처음 2~4주는 **초안 → 승인 → 업로드** 2단계로 간다.
- `insta_main`(초안 만들기) 자동화: 소재·글·카드까지 만들고 드라이브 `부업/인스타/main/초안/YYYY-MM-DD/` 에 카드 8장 + `caption.txt` + `preview.png`(8장 이어붙인 한 장) 저장. 상태 파일 요약: "초안 1건 · 검토 필요".
- 사용자가 폴더를 보고 마음에 들면 `승인/` 폴더로 옮긴다(또는 파일명 앞에 `OK_`).
- `insta_main_publish`(업로드) 자동화: `승인/` 에 있는 초안을 올리고 `게시됨/` 으로 옮긴다. 예약 실행(매일 08:00) 또는 ▶ 시작.
- 톤이 잡히면 두 자동화를 하나로 합쳐(승인 생략) 완전 자동으로 바꾼다. 설정값 `require_approval: true/false` 하나로 전환.

두 자동화는 같은 워크플로(`insta.yml`)를 쓰고 `inputs.mode` 만 다르다 — 사무실 설정의 `inputs` 항목으로 이미 가능.

### 2.6 학습(성과 피드백)

업로드 다음 날 `GET /{media_id}?fields=like_count,comments_count` + 인사이트(`saved`, `shares`, `reach`)를 읽어 `history` 와 드라이브 시트에 기록. 상위 3개의 원고를 "우리 계정 참고 예시"로 프롬프트에 자동 포함하고, 하위는 제외. 이것이 "잘 나오게" 만드는 유일한 지속 장치다. 좋아요만 보지 않고 **저장·공유** 를 우선 지표로 삼는다(2026 알고리즘 신호).

## 3. 주제 프로필 — 커스터마이징의 단위

주제별 차이는 코드가 아니라 `automations/insta/profiles/<이름>.yaml` 하나로 흡수한다. 계정 설정(`config.actions.yaml`)이 어떤 프로필을 쓸지 가리킨다.

```yaml
# profiles/ai_tips.yaml (3번 주제)
name: AI 툴·프롬프트 꿀팁
audience: "AI 를 업무에 쓰고 싶은 20~40대 직장인. 개발자 아님."
tone: "친한 선배가 알려주는 말투. 반말 아님, 존댓말 짧게. 과장 금지."
format: list            # list | research | checklist | notice
slides: 8
hook_patterns: ["숫자형: ~N개", "손해형: 모르면 매달 N시간 낭비", "반전형: 다들 X 쓰는데 사실 Y"]
```

## 4. 비용·제약 정리

| 항목 | 비용 | 비고 |
|---|---|---|
| 글 생성 | **무료** — Claude 구독(Claude Code CLI 토큰) 1순위, Gemini 무료 등급 대체 | 유료 API 키 없음. 구독 사용량 한도 안에서 사용 |
| Cloudflare R2 | 무료 | 10GB, 카드 한 장 200KB → 5만 장 |
| GitHub Actions | 무료(공개 저장소 아님 → 월 2,000분) | 실행 1회 3~5분, 하루 2회면 월 300분 |
| Instagram API | 무료 | 하루 100건 제한 |
| Playwright Chromium | 무료 | 실행마다 설치 1분(캐시 가능) |

제약: 계정이 개인 계정이면 API 불가(프로페셔널 전환 필수). 앱 심사 없이 내 계정만. 이미지는 JPEG. 인스타 토큰 60일. Claude 구독 토큰도 만료·재발급이 있을 수 있어(`claude setup-token` 재실행) 실패 시 Gemini 로 넘어가고 배너로 알린다.

**돈 드는 것: 없음.** 인스타그램 API·GitHub Actions(월 2,000분)·Cloudflare R2(10GB)·Playwright·글꼴·RSS 모두 무료. 유일하게 돈이 들 수 있던 글 생성은 이미 내는 Claude 구독으로 해결한다.

## 5. 결정이 필요한 것 (사용자)

1. **계정 이름**(영문, 예 `main`)과 인스타그램 계정 준비 상태: 프로페셔널 전환·Meta 개발자 앱은 안내에 따라 직접 해야 한다(비밀값은 GitHub Secrets 에 직접 입력).
2. **글 생성**: Claude 구독 토큰(`claude setup-token`, 이 PC 에서 1회) + Gemini 무료 키(대체용) — 둘 다 GitHub Secrets 에 직접 입력. 결제 없음.
3. **이미지 호스팅**: R2(추천, 무료, Cloudflare 설정 1회) vs 저장소 public 폴더(임시, 설정 없음).
4. **처음엔 승인 단계를 둘지**(추천: 둔다. 2~4주 뒤 자동 전환).
5. 하루 몇 건·몇 시(추천: 1건, 소셜비즈 리포트상 소비가 몰리는 19~22시 직전인 **18:30**, 주말 포함).
