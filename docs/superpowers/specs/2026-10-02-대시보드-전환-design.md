# 대시보드 전환 (2026-10-02)

사용자 결정: 픽셀 사무실(캐릭터) 화면을 일반 대시보드로 바꾼다. 샘플(클로드 디자인 캔버스)을 보고 "이 방향으로 실제 사이트에 적용"을 승인했다.
세 사무실(`/assembly`·`/home`·`/side`) 공통 화면이라 한 번에 적용했다.

## 바뀐 것

- 화면 구성: 머리글(사무실 탭·마지막 확인) → 제목·전체 시작 → 배너 → 요약 5칸 → 자동화 카드 + 옆 패널 → 실행 이력.
- 픽셀 월드·캐릭터를 뺐다. 월드에만 있던 **팀(부서) 이름**은 카드 머리에, 직원 상태는 카드의 작업 줄에 있다.
- 사이트가 이미 받고 있었지만 안 보이던 값 두 가지를 카드에 넣었다: **걸린 시간**(`duration_sec`), **방식**(`trigger`).
- 요약에 **그 날 실행 횟수**(성공·실패·평균 소요) 칸, 옆 패널에 **시간대별 실행 횟수 막대**와 **언제 실행되나** 목록을 더했다.
- 실행 이력은 30줄까지만 먼저 보이고 "N건 더 보기"로 펼친다(가계부처럼 하루 수백 번 도는 자동화 때문).
- 그림 문자 대신 선 아이콘. 상태는 색 + 아이콘 + 글자를 함께 쓴다.
- 글꼴 IBM Plex Sans KR(본문) + Archivo(숫자). 사무실 대표 색 = `--accent`(`--c-600`), 연한 색 = `--accent-soft`(`--c-100`).
