# 주식 분석 봇 4단계 — 국내 종목 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 코스피·코스닥 대표 약 350종목을 미국과 같은 방식(점검표 7가지·발굴 네 관점·관심 종목·해석)으로 매일 점검하고, 화면에서 미국 · 국내를 바꿔 볼 수 있게 한다.

**Architecture:** 자료는 **야후 파이낸스(yfinance)의 국내 종목(`005930.KS`, `247540.KQ`)** 으로 받는다 — 2026-10-06 확인: 삼성전자·네이버·에코프로비엠 모두 1년 시세·예상 PER·매출 증가율·영업이익률·부채·현금흐름·실적 발표일·업종이 들어온다. 그래서 수집·계산·저장·화면 코드는 그대로 두고 **시장(`market`)을 매개변수로** 흘려보낸다. 지수는 코스피(`^KS11`). 공시(DART)는 이번에 받지 않는다(사건 관점은 가격 조건만, 화면이 그렇게 적는다).

**Tech Stack:** 1~3단계와 같다. 국내 대상 목록을 한 번 뽑을 때만 `krx_openapi`(이미 설치, 인증키는 개인 폴더).

**Spec:** `docs/superpowers/specs/2026-10-05-주식-분석-봇-design.md` §4.1~4.3, §9의 4단계. 앞 단계 계획: 같은 폴더의 1·2·3단계 문서.

## Global Constraints

- 매일 실행에 AI 호출 없음. 등급·목표가·매수/매도 문구 없음. "투자 권유가 아님" 유지.
- 공개 저장소·Actions 로그 → 실행 출력·상태 파일·일지는 **건수만**(종목 코드·이름 금지, 예외는 `type(exc).__name__` 만).
- **비밀값 파일은 열어 보지 않는다.** 국내 목록을 뽑을 때 `ai-home/02_주식신호/config.yaml` 의 `krx_api_key` 는 코드가 읽기만 하고, 값은 출력·보고서·커밋·채팅 어디에도 적지 않는다.
- 사이트 로그인 없음 → Worker 엄격 검사(국내 코드는 `^[0-9]{6}$`, 이미 있음), 화면은 `normalize*` 뒤 글자로만 그린다.
- 예약은 `worker/schedule.ts` 에만. 값이 없으면 `None`/"자료 없음". 문턱값은 `rules.yaml`(국내도 같은 값).
- 상태는 색 + 아이콘/부호 + 글자, 그림 문자 금지. 자산·투자팀 6석 상한 — **자동화·직원을 늘리지 않는다**(국내도 같은 카드 `analyst`).
- 세 사무실과 1~3단계 화면(미국)이 깨지지 않아야 한다. `?mock=1` 화면은 미국 견본 그대로.
- 이 PC: `/usr/bin/bash scripts/npm.sh <test|tsc|build>`, `python -m pytest -q automations/analyst`. 커밋 끝줄 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. 푸시하지 않는다.

## 이번 단계에서 정한 것 (설계서와 다른 점)

| 정한 것 | 이유 |
|---|---|
| 네이버 금융·DART 대신 **야후 파이낸스** | 네이버 금융은 2026년에 화면 구조가 바뀌어 긁기 어렵고, DART 는 인증키 발급·회사 코드 대조가 필요하다. 야후가 같은 모양으로 다 준다. 공시는 나중에 DART 로 붙일 수 있게 `filings_for` 자리를 비워 둔다 |
| 국내 공시 없음 → 사건 관점은 가격 조건만 | 3단계까지의 `filings_ok=False` 문장이 그대로 설명한다 |
| 국내 대상은 **시가총액 상위 350종목(코스피 250 + 코스닥 100)** 을 한 번 뽑아 파일로 둔다 | 미국 S&P 500 과 같은 방식. 갱신은 사람이 가끔 다시 뽑는다 |
| 미국·국내가 **한 카드**를 쓴다(상태 파일 하나) | 6석 상한. 요약 줄 앞에 `미국`/`국내`를 붙여 어느 실행인지 보이게 한다 |
| 국내 기사 제목은 구글 뉴스 **한국어**(`hl=ko&gl=KR&ceid=KR:ko`, 질의 `<회사 이름> 주식`) | 같은 함수에 인자만 더한다 |
| 금액 단위: 국내는 **원**(현재가 `₩71,500`, 큰 돈 `1,691억 원`), 미국은 그대로 달러 | 종목 자료에 `currency`("USD"/"KRW")를 넣고 화면 함수가 그것을 본다 |

## 자료 모양 (늘어나는 것)

```text
universe_kr.txt 한 줄     005930 KS  # 삼성전자        (코드 거래소  # 한글 이름; 거래소는 KS=코스피 KQ=코스닥)
record 추가               "currency": "USD" | "KRW", "name_local": "삼성전자" | None   # 국내는 화면 이름을 한글로
board row 추가            "currency"
index 파일 (kr)           {"t": "KOSPI", "closes": [...]}
status summary            "미국 · 점검 503건, …" / "국내 · 점검 350건, …"
화면 주소                 /home/stock?market=kr · /home/stock/discover?market=kr · /home/stock/kr/005930
```
