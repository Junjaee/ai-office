# 3단계 — 기업 읽기 (곁가지)

가격 말고 회사 자체의 숫자와 사건. 개별 종목을 다루면 **실적 발표**를 피할 수 없어서, 그 부분을 앞에 둔다.
확인일: 2026-09-21.

## 1. 실적 발표 — 개별 종목의 가장 큰 사건

- 미국 상장사는 분기마다(1·4·7·10월 중순부터 약 6주가 몰리는 철) 실적을 발표한다. 대부분 **장 시작 전**이나 **장 마감 뒤**에 내놓는다.
- 주가는 "좋았나"가 아니라 **"예상보다 좋았나"**로 움직인다. 이익이 늘어도 시장 예상에 못 미치면 급락한다. 다음 분기 전망(가이던스)이 실적보다 더 크게 작용하는 일도 흔하다.
- 미국은 하한가가 없다. S&P 500 구성 종목 20년치를 직접 세어 보니(2016년 이후) **시가가 전날 종가와 5% 넘게 벌어진 날이 종목·거래일 기준 0.73%**, −10% 넘게 빠져 시작한 날이 0.065%, 최악은 −48%였다. 같은 기간 지수 ETF 는 5% 넘는 틈이 0.22%, 최악 −10.4%. 이런 틈은 손절 주문으로 막을 수 없다(손절가를 건너뛰고 체결된다).
- 503종목이면 0.73%는 **하루 평균 3~4종목**이 그렇게 움직인다는 뜻이다. 남의 일이 아니다.

→ 자동화
- 신호를 낼 때 **그 종목의 다음 실적 발표일**을 같이 본다. "발표가 N거래일 안이면 새로 사라는 신호를 내지 않는다 / 알림에 경고를 단다"를 선택지로 둔다(쓸지 말지는 사용자 결정).
- 일정 출처(직접 확인): **나스닥 실적 달력 API**(`api.nasdaq.com/api/calendar/earnings?date=YYYY-MM-DD`) — 열쇠 없이 날짜별 전 종목(티커·발표 시간대·예상 EPS)을 준다. 5일치 75건에 16초. 야후(`yfinance` 의 `calendar`)는 종목에 따라 실적일이 빠져 있었다(배당일만 나옴) → 보조로만.
- 발표일은 회사가 바꾸기도 한다. 매 실행 때 앞으로 2주치를 새로 받는다.

## 2. 재무제표 세 장

| 표 | 묻는 것 | 핵심 줄 |
|---|---|---|
| 손익계산서 | 얼마 벌었나 | 매출 → 영업이익 → 순이익 → 주당순이익(EPS) |
| 재무상태표 | 무엇을 갖고 얼마를 빚졌나 | 자산 = 부채 + 자본. 현금, 차입금 |
| 현금흐름표 | 실제 돈이 들어왔나 | 영업활동 현금흐름, 잉여현금흐름(FCF = 영업현금 − 설비투자) |

- 이익은 회계상 숫자라 꾸밀 여지가 있고, 현금흐름은 그러기 어렵다. 이익은 나는데 영업현금이 계속 마이너스면 경고.
- 미국 회사는 자사주 매입으로 주식 수를 줄여 EPS 를 올리는 일이 흔하다 → 순이익과 EPS 를 같이 본다.

## 3. 비율 읽기

| 지표 | 뜻 | 읽을 때 주의 |
|---|---|---|
| PER (주가 ÷ EPS) | 이익의 몇 배 값에 거래되나 | 성장 빠른 회사는 원래 높다. 적자면 계산 불가. 과거 12개월 기준인지 예상치 기준인지 확인 |
| PBR (주가 ÷ 주당순자산) | 장부 가치의 몇 배인가 | 공장·은행엔 의미 있고, 소프트웨어 회사엔 거의 의미 없다(자산이 장부에 안 잡힘) |
| ROE (순이익 ÷ 자본) | 주주 돈으로 얼마나 버나 | 빚을 많이 쓰거나 자사주를 많이 사면 부풀려진다 |
| 영업이익률 | 매출에서 남기는 비율 | 업종 안에서만 비교 |
| 배당수익률 | 주가 대비 연 배당 | 주가가 폭락해도 높아진다 |
| 부채비율·이자보상배율 | 빚을 감당할 수 있나 | 금리 오를 때 중요 |

- **업종이 다르면 숫자의 의미가 다르다.** 비교는 같은 업종 안에서, 또는 그 회사의 과거와 한다. S&P 500 은 11개 업종(GICS)으로 나뉘고, 위키 목록 표에 업종이 들어 있다(2단계).
- 싸 보이는 데는 이유가 있는 경우가 많다(가치 함정). "저PER 이니 산다"는 규칙은 검증 없이는 쓰지 않는다.

## 4. 공시

### 미국 (SEC EDGAR)

| 서류 | 내용 | 시점 |
|---|---|---|
| 10-K | 연간 보고서(감사 받음) | 회계연도 끝나고 60~90일 |
| 10-Q | 분기 보고서 | 분기 끝나고 40~45일 |
| 8-K | 중요한 일이 생겼을 때(실적 발표, 인수합병, 대표 교체 등) | 4영업일 안 |
| Form 4 | 임원·대주주의 자사 주식 매매 | 2영업일 안 |

- 직접 확인: `data.sec.gov` 가 열쇠 없이 **회사별 공시 목록**과 **재무 수치(XBRL)** 를 JSON 으로 준다(EPS 분기별 338건, 최근 공시 목록 정상). 요청 머리말에 연락처를 밝히는 것이 조건이고 초당 10회 제한. 티커 ↔ 회사번호(CIK) 표도 있고, 위키 목록에도 CIK 가 있다.
- 숫자가 공시된 **날짜**(`filed`)가 같이 온다 → 검증할 때 "그날 알 수 없었던 숫자"를 쓰는 실수를 막을 수 있다(7단계).

### 한국 (DART)

- 금융감독원 전자공시. 사업·분기보고서, 주요사항보고(증자·감자·합병), 지분 공시. 오픈 API 는 무료 열쇠를 발급받아야 한다(새 비밀값 필요).
- 한국은 **유상증자·전환사채** 공시가 주가에 미치는 영향이 크다(주식 수가 늘어 가치가 희석).

## 5. 주식 수가 바뀌는 사건

- **액면분할·병합**: 가치는 그대로, 숫자만 바뀐다. 수정주가로 처리된다(2단계).
- **배당**: 배당락일에 그만큼 빠진다. 수정주가로 처리.
- **자사주 매입**: 주식 수 감소 → EPS 상승.
- **증자·전환**: 주식 수 증가 → 희석.
- **분사(스핀오프)**: 회사 일부가 새 종목으로 떨어져 나온다. 새 종목은 이력이 짧다(2단계에서 본 이력 짧은 4종목 중 일부가 이 경우).
- **인수합병**: 인수되는 쪽은 인수가 근처에 붙어 움직이지 않게 된다. 지수에서 빠진다.

## 6. 자동화 설계로 넘길 것

1. 매 실행 때 앞으로 2주치 실적 일정을 나스닥 달력에서 받아, 신호 종목에 "실적 발표 D-N" 표시를 단다. 발표 임박 종목의 신규 매수 신호를 막을지는 설정값(사용자 결정).
2. 재무 기반 규칙(저PER·고ROE 등)은 1차 범위에서 뺀다. 가격 기반 규칙이 자리 잡은 뒤, SEC 재무 수치로 **공시일 기준**으로 붙인다.
3. 한국 공시(DART)를 쓰게 되면 열쇠가 새 비밀값으로 필요하다.
4. SEC·나스닥 요청에는 개인 식별 정보를 넣지 않는다(저장소 이름 수준의 표시만).
