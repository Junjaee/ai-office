# 주식 매매신호 자동화 — 지식 창고

매매신호 자동화(알림형)를 만들기 전에, AI 가 주식의 기본을 단계별로 조사해 적어 두는 곳이다.
다음 대화에서도 AI 가 이 폴더를 먼저 읽고 이어서 작업한다(AI 는 대화가 끝나면 기억이 남지 않으므로 "학습 = 이 문서들"이다).

## 정해진 것 (사용자 결정 2026-09-21)

- **주문은 사람이 한다.** 미래에셋증권은 개인용 주문 API 가 없다. 자동화는 조건이 맞으면 텔레그램으로 신호만 보내고, 매수·매도는 사용자가 미래에셋 앱에서 직접 한다.
- **미국주식이 주력, 한국주식은 보조.** 문서마다 미국을 먼저 쓰고 한국을 뒤에 쓴다.
- **미국 쪽 대상은 S&P 500 구성 종목 위주.** 거래가 많고 가격 이력이 깨끗한 대형주로 범위를 좁힌다.
- **AI 는 종목·전략을 추천하지 않는다.** 규칙의 원리와 검증 방법까지만 정리하고, 어떤 규칙을 쓸지는 사용자가 정한다. 실제 주문도 AI 가 넣지 않는다.
- **저장소가 공개다.** 이 폴더에는 누구나 봐도 되는 일반 지식만 적는다. 보유 종목·수량·관심 종목·실제 쓰는 규칙은 개인 폴더(`ai-stock/`, gitignore)와 텔레그램에만 둔다.

## 문서 쓰는 규칙

- 단계마다 파일 하나: `NN-<제목>.md`.
- 각 항목은 **사실 → 신호 자동화에 주는 의미** 순서로 쓴다. 자동화와 상관없는 상식은 줄인다.
- 세율·수수료·거래시간처럼 **바뀌는 숫자에는 확인한 날짜와 출처**를 단다. 확인 못 한 것은 "확인 필요"로 남긴다(지어내지 않는다).
- 문서 끝에 "자동화 설계로 넘길 것"을 모은다. 8단계에서 이것들만 모아 설계서를 쓴다.

## 지금까지의 핵심 결론 (2026-09-21)

- 시세는 무료로 된다: 야후로 S&P 500 전 종목 20년치가 85초. 저장하지 않고 매번 새로 받는다.
- 가만히 든 지수 ETF(연 10.9%, 낙폭 −55%)가 강한 기준선이다. 교과서 규칙 여섯 개 중 위험 대비 수익으로 이것을 넘은 것은 없었다. 규칙의 쓸모는 낙폭을 고르는 데 있다.
- 거래가 잦은 규칙은 수수료(편도 0.25%)에 죽는다. 한 달에 몇 번 움직이는 규칙만 후보.
- 무료 데이터에는 사라진 회사가 없어 개별 종목 규칙의 성적이 부풀려진다(구성 종목이었던 961개 중 501개만 시세가 있음).
- 급락 때 2배 ETF 로 갈아타는 구조: 최근 15~20년엔 거의 어떤 조건이든 통했지만 그 수익은 시점이 아니라 레버리지에서 나왔고, 닷컴형 하락에서는 옮긴 돈이 −98%, 20년 묶였다. 발동이 몇 년에 한 번이라 표본이 작다.
- 조건을 4만 가지로 잘게 나눠 돌린 결과(10번): 성적의 74~80%가 '레버리지를 얼마나 오래 들었나' 하나로 설명됐고, 노출이 같은 판단 없는 고정 배분과 견주면 대다수가 졌다(중앙값 0.96~0.99). 앞 절반 1등을 골라도 뒤 절반에서는 레버리지 덕일 뿐이었고, 실력이 있을 수 없는 가짜 시장에서도 진짜 1등만큼의 성적이 24% 확률로 나왔다. 머신러닝은 같은 빈도의 동전던지기와 구별되지 않았다. **결론: 고를 수 있는 것은 레버리지 수준 하나뿐이고, 조건을 다듬는 일은 헛수고다.**
- 퀀트 전 갈래를 돌린 결과(11번): 규칙 3,200개 중 2016년 이후 SPY 보다 샤프가 높은 것은 7%, 자산배분 369개 중 SPY 보다 많이 번 것은 0개, 머신러닝·딥러닝 7종은 **변동성을 맞추면 전부 SPY 에 짐**. 최고 성적 신호(저가주)와 모델이 학습한 유일한 패턴이 같았고 둘 다 생존편향이었다(그 특징을 빼면 예측력 t값 0.07). 앞 10년에서 1등을 고르면 뒤 10년에 SPY 를 이긴 비율 0%. **자산배분·타이밍은 수익이 아니라 낙폭을 사는 도구**(−55%→−27%, 수익 10.9%→9.8%).
- 재무제표를 붙이니 결론이 바뀐다(12번): **가치·주주환원 팩터는 검증을 전부 통과**했다 — 예측력 t 2.4~3.5, 복합:가치 상위20 분기가 2011~ CAGR 21.8%/낙폭 −17%/샤프 1.59(SPY 14.1%/−34%/0.86), 앞 기간에서 고른 것이 뒤 기간에서도 통함(순위상관 +0.59), 시세 보유율 97% 시기에 오히려 더 강함, 점수 뒤섞기 200회 중 실제만큼 좋은 것 0, 조건 20칸 전부 SPY 위, 세후로도 +4.7%p. 퀄리티·성장은 0. 머신러닝 12개는 전부 단순 평균 규칙보다 못함(최고 샤프 1.04). 한계: 2011~14 는 생존편향으로 부풀려졌을 것, 2015~18 은 4년간 예측력 0, 집중 투자. **11번의 결론은 가격만 봤을 때의 결론이었다.**
